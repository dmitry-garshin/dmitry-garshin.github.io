# garshin — сайт-визитка

Одностраничный статический сайт: белый фон, чистая типографика и pill-кнопки в духе brevo.com,
карандашный скетч «Ёж за ноутбуком» с подписью «трудюсь».

## Структура

```
index.html                 — страница
css/style.css              — стили (цвета — переменные в :root)
images/hedgehog.svg        — скетч ежа (векторный, чёрно-белый)
tools/generate_hedgehog.py — генератор скетча (python tools/generate_hedgehog.py)
```

## Запуск

Сборка не нужна — просто откройте `index.html` в браузере.
Для публикации подойдёт любой статический хостинг (GitHub Pages, Netlify, Cloudflare Pages).

## Что поменять под себя

- Имя/логотип `garshin` — в `index.html` (шапка, подвал, `<title>`).
- Email в блоке «Контакты» — сейчас заглушка `hello@example.com`.
- Тексты карточек «Чем занимаюсь».
- Иголки ежа: поменяйте `SEED` в генераторе и перезапустите его.
